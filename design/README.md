# Lunti design handoff

1. Copy this whole folder into your app repo as `/design`.
2. Give your coding assistant the prompt at the end of `DESIGN_HANDOFF.md` (section 8).
3. To click through the design yourself, open `screens/Landing.html` in a browser.

- `DESIGN_HANDOFF.md` — tokens, components, screen list, navigation map, rules, open decisions
- `screens/` — every screen as plain HTML (needs internet for the web font)
- `screenshots/` — every screen as a PNG (@2x)
- `source/` — original canvas files
- `assets/` — logo files
